# Security and privacy reporting

Please do not disclose vulnerabilities or privacy failures in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include:

- the affected component and commit;
- reproduction steps using synthetic data;
- expected and observed behavior;
- potential impact on capture state, raw media, permissions, or action approval;
- a suggested mitigation, if known.

Do not attach real wearable recordings, health data, credentials, access tokens,
keystores, or personally identifying transcripts. Redact logs before sharing.

The maintainer will acknowledge a complete report when available, validate the
issue, and coordinate a fix before public disclosure. This prototype does not
currently promise a formal response-time SLA.
